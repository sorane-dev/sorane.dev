sorane**Docs**（Powered by [ibisOffice](https://github.com/ibisjp/ibis-office)）は、Web とネイティブアプリの両方で利用できます。

## Web アプリ

- **[docs.sorane.dev ↗](https://docs.sorane.dev/)**
- ブラウザ（WebAssembly + WebGPU）上で直接動作します。アカウント登録なしで手元の文書を開いて閲覧・編集・PDF 書き出しできます。

## デスクトップ・モバイルアプリ

| プラットフォーム | 配布形式 | 備考 |
| --- | --- | --- |
| **macOS (Apple Silicon)** | `.app` バンドル | GitHub Releases（マイルストーン配布） |
| **Windows (x64)** | ZIP パッケージ | GitHub Releases（マイルストーン配布） |
| **Linux (x64 / arm64)** | AppImage / Flatpak | AppImage は署名付きビルド来歴（GitHub Artifact Attestations）に対応 |
| **Android (arm64 / x86_64)** | APK / Google Play (AAB) | Google Play ストア公開準備中（API 36・16 KB ページサイズ対応） |
| **iOS (arm64)** | ネイティブビルド | 開発・検証ビルド |
