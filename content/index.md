**文書をひらく。ひらめきが、広がる。**

sorane**Docs**（Powered by [ibisOffice](https://github.com/ibisjp/ibis-office)）は、ブラウザ（WebAssembly + WebGPU）でもデスクトップ・モバイルアプリでも、端末内完結で文書をひらいて、読んで、編集できるオープンソースのオフィスアプリです。

- **[Web 版をひらく (docs.sorane.dev) ↗](https://docs.sorane.dev/)** — アカウント不要・ブラウザだけで今すぐ試せます
- **[サンプルを試す](samples.html)** — 一太郎・Excel・Visio・Mermaid・自治体連携 CSV・SBOM の 7 件のサンプル
- **[アプリと対応プラットフォーム](apps.html)** — Web / macOS / Windows / Linux / Android / iOS

## 主な特徴

- **幅広い文書形式に対応**: Word（`.docx`）・Excel（`.xlsx`）・PowerPoint（`.pptx`）に加え、一太郎（`.jtd`）・DocuWorks（`.xdw`）・Visio（`.vsdx`）・Markdown（Mermaid 図対応）・自治体連携標準 CSV（構造化ビュー）・CycloneDX SBOM（JSON）に対応しています。
- **端末内完結のローカル処理**: 文書の読み込み・編集・PDF 書き出しはすべてお使いの端末内で処理されます。
- **日本語組版へのこだわり**: 縦書き・罫線表・異体字対応フォントなど、日本の業務文書・行政文書を扱うための機能を強化しています。
