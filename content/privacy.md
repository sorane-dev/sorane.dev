最終更新日: 2026年11月25日 · 対象: sorane**Docs**（Android / iOS / macOS / Windows / Linux / Web）

## 1. 基本方針

sorane**Docs**（Powered by [ibisOffice](https://github.com/ibisjp/ibis-office)）は、利用者のプライバシーを尊重し、文書の閲覧・編集・書き出しを端末内で完結して処理するように設計されています。

## 2. 収集する情報

- **Android / iOS / デスクトップアプリ**: 利用者の個人情報、位置情報、連絡先、広告 ID、利用状況のトラッキングデータ、または開いた文書の内容を運営者や第三者のサーバーへ自動送信・収集することはありません。
- **端末内ファイルへのアクセス**: 利用者がファイル選択画面（Android の Storage Access Framework 等）や共有機能を通じて明示的に指定した文書のみを読み込み・保存します。
- **Web 版（`docs.sorane.dev`）の任意機能**: ログインせずに利用する場合はブラウザ内（WebAssembly）で処理されます。利用者が明示的にログインし、クラウド保存（ファイル・リポジトリ）や AI アシスタント機能を利用した場合に限り、その機能の提供に必要な認証情報・保存文書・入力プロンプトがサーバーへ送信されます。

## 3. ネットワーク権限の利用目的（Android）

Android 版アプリでは、文書内の外部リンクやライセンス・プロジェクトページをブラウザで開く機能、および将来的な任意のネットワーク連携のために `INTERNET` 権限を宣言しています。利用者の操作なしに文書データや個人情報を送信することはありません。

## 4. 第三者提供・広告・解析

soraneDocs には広告 SDK や行動追跡用のサードパーティ解析 SDK を組み込んでいません。

## 5. お問い合わせ

本プライバシーポリシーやデータの取り扱いに関するお問い合わせは、[GitHub Issues](https://github.com/masanork/ibis-office/issues) よりご連絡ください。

## Privacy Policy (English)

Last updated: November 25, 2026 · Scope: sorane**Docs** (Android / iOS / macOS / Windows / Linux / Web)

### 1. Overview

sorane**Docs** (Powered by [ibisOffice](https://github.com/ibisjp/ibis-office)) is designed to open, edit, and export documents locally on your device.

### 2. Data Collection

- **Android / iOS / Desktop apps**: We do not collect, transmit, or sell personal data, location data, contacts, advertising IDs, analytics/telemetry, or the contents of documents you open.
- **File access**: The app only accesses files that you explicitly select or share using the system file picker (such as Android Storage Access Framework).
- **Optional Web features (`docs.sorane.dev`)**: Without signing in, documents are processed locally in your browser via WebAssembly. Only when you explicitly sign in to use optional cloud storage or AI assistant features are the authentication tokens, saved documents, or prompts transmitted to provide those features.

### 3. Network Permission (Android)

The Android app declares the `INTERNET` permission to allow opening external links (such as document hyperlinks or license pages) and optional user-initiated network features. No document contents or personal data are transmitted without your action.

### 4. Advertising and Third-Party Tracking

soraneDocs does not include advertising SDKs or third-party behavioral tracking SDKs.

### 5. Contact

If you have questions about this Privacy Policy, please contact us via [GitHub Issues](https://github.com/masanork/ibis-office/issues).
